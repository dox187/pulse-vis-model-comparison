# Original application prompt

The original project request, recovered from the Claude development session. Only line wrapping and surrounding paste markup have been removed; the wording is unchanged. The same wording appears in the GPT and Bonsai project requests.

> Create a PulseAudio-compatible TUI visualizer application. It should include the most well-known and widely used audio visualization modes. Allow for the configuration of colors, sensitivity, quality, etc. It should be able to display the entire output or filter by specific applications if multiple apps appear among the playback sources. Use the Rust programming language for a native experience. Let me know if you need any libraries installed.

This is the application-building prompt, not the later request to audit the models, add screenshots, or publish the repository. Agent system instructions, local environment context and follow-up messages differed between runs, so a shared task prompt alone does not make this a fully controlled benchmark.
